## 🚀 Featured Projects

### 🔬 PaperPilot AI — Multi-Agent Research OS

Multi-agent research platform built with **LangGraph, Gemini API, ChromaDB, FastAPI, Next.js, and SQLite WAL**.

▸ Retrieves, re-ranks, and synthesizes academic papers
▸ Multi-agent research workflow
▸ RAG-based literature analysis
▸ APA / IEEE / BibTeX citation generation
▸ Automated research reports

### 📄 DocuMind AI — Enterprise Document Intelligence

AI-powered document processing platform using **FastAPI, Gemini Multimodal, Tesseract OCR, PostgreSQL, AWS S3, React, and TypeScript**.

▸ Multi-format document processing
▸ AI-powered structured field extraction
▸ Confidence-based verification workflow
▸ Duplicate and fraud detection
▸ PostgreSQL + AWS S3 audit storage

### 🔗 Linkly — Secure URL Shortener & Analytics SaaS

High-throughput URL shortening platform built with **FastAPI, Redis, PostgreSQL, Docker, Next.js, Google OAuth 2.0 PKCE, and JWT**.

▸ High-throughput redirect service
▸ Redis TTL-based caching
▸ Secure Google OAuth authentication
▸ Malware scanning for redirect protection
▸ URL analytics
